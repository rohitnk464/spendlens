# Go-To-Market Strategy: SpendLens (Credex Lead-Gen Asset)

SpendLens is positioned as a free, highly viral utility built specifically to capture high-intent B2B startup leads for Credex. We bypass traditional broad-marketing approaches in favor of granular, community-first distribution.

---

## 1. The Ideal Customer Profile (ICP)

Our exact target user is **not** a generic "startup." We target a hyper-specific buyer:
*   **Job Title:** CTO, VP of Engineering, or Fractional CFO.
*   **Company Stage:** Seed to Series A AI-native startups (10 to 50 employees).
*   **The Pain Point:** Startups at this stage have scaled their developer count rapidly, resulting in bloated billing. They are paying for overlapping Cursor, Claude Pro, and GitHub Copilot seats concurrently for the same engineers, alongside heavy, raw OpenAI/Anthropic developer API bills.

---

## 2. High-Intent User Search & Scroll Behaviors

Before discovering SpendLens, this ICP is actively searching or scrolling for these exact terms:
*   **Search Engine Queries:** *"Is Cursor Teams worth it vs Pro"*, *"Anthropic prompt caching API price drop"*, *"how to audit company AI subscription burn"*, *"Claude API batch queue discount setup"*.
*   **X (Twitter) Scrolling Focus:** Engaged with engineering threads discussing dev-tool fatigue, dev-tool stack consolidation, and comments on posts by founders complaining about LLM token overheads.

## 4. Acquiring the First 100 Users in 30 Days (With $0 Budget)

We will execute three highly directed organic plays to acquire our first 100 high-intent leads:

### Play 1: Programmatic Cold Dev-Audit Outreach (CTO Focused)
*   **Tactics:** Scrape public GitHub developer profiles or LinkedIn for 10-30 employee AI startups. Identify teams listing "Cursor" or "Claude" as primary tools. 
*   **Outreach:** Send a hyper-personalized cold DM to the CTO: 
    > *"Hey [Name], saw your dev team is scaling. Analysis shows startups your size waste an average of $280/mo on Cursor Teams vs Pro seat overlap, plus 40% on raw API token redundancies. Ran a free, deterministic spend audit tool for you here: [spendlens.com]. Takes 30s, no Plaid or card required."*
*   **Target:** 20 outreaches/day → 10% conversion → **60 high-intent audits in 30 days**.

### Play 2: Value-Add Hacker News Launch
*   **Tactics:** Post a text thread on Hacker News sharing aggregate data rather than just a link.
*   **Title:** *“Show HN: I analyzed 100 startup developer stacks. 45% pay for overlapping Cursor and Copilot seats. Here is the math.”*
*   **Call-to-Action:** Provide a link to the free auditing wizard. This establishes organic technical credibility.
*   **Target:** **200+ completed audits** within 48 hours.

### Play 3: Programmatic SEO Comparison Directory
*   **Tactics:** Generate comparison landing pages using our verified local pricing database: `spendlens.com/compare/cursor-teams-vs-pro`, `spendlens.com/compare/claude-api-vs-openai-api`.
*   **Target:** Captures high-intent organic search queries directly.
